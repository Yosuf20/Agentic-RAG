📌 Features

Everything you need to query smarter

Six powerful capabilities under one roof — all running locally.

📄

PDF Question Answering

Upload any PDF and ask natural-language questions. Documents are chunked intelligently for precise retrieval.

🔎

Hybrid Retrieval

Combines FAISS vector similarity and BM25 keyword search for best-of-both retrieval quality.

🌐

Web Search Agent

Queries requiring current or external information are routed to Tavily for live web search.

🧠

Supervisor Agent

A routing agent analyses each query and delegates to the right specialist. Supports multi-hop ReAct-style loops.

🔄

LangGraph Workflow

Agents communicate through a shared graph state — enabling agent → supervisor → agent loops with full message history.

🏠

Local LLM via Ollama

All inference runs on your machine using Qwen3:4B through Ollama. Privacy-first, no API keys for LLM.

⚙️ Process

How it works in 3 steps

From PDF upload to intelligent answer — all automated.

1
📤

Upload & Process

Drop your PDF. The system chunks, embeds it into FAISS, and indexes it with BM25 for hybrid retrieval.

2
🤔

Supervisor Routes

Your question hits the Supervisor Agent. It decides: does this need the PDF Agent or the Web Agent?

3
💬

Answer Delivered

The specialist agent retrieves context and Qwen3 synthesises a precise, cited answer — streamed back to you.
